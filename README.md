# Atulya Toy’s Shop

A polished static toy storefront built with HTML, CSS, and JavaScript.

## Project Summary

`toyshop` is a small, fully client-side website for a toy store called **Atulya Toy’s Shop**. It includes a home page, shop catalog, about page, and contact page, with interactive features that make the browsing experience feel modern and engaging.

## Unique Strengths

- **Story-driven identity:** The About page contains a strong brand story about a magical toy factory and the founder Atulya, giving the site personality beyond a generic store layout.
- **Interactive shop experience:** The shop page supports live product filtering, cart management, and persistence through `localStorage`.
- **Polished front-end behavior:** The site includes a loader animation, random hero image selection, dark/light theme switching, and a scroll-to-top button.
- **Mobile-friendly structure:** Responsive CSS grid layout and flexible styling support a clean display across screen sizes.

## Core Features

- **Home page (`index.html`)**
  - Random toy hero image each load
  - Navigation with active page highlighting
  - Theme toggle for light/dark appearance

- **Shop page (`shop.html`)**
  - Live search filter for product names
  - Add-to-cart buttons with duplicate protection
  - Cart summary showing item count and total price
  - User cart saved in browser `localStorage`

- **About page (`about.html`)**
  - Brand story and mission narrative
  - Magical toy factory theme to reinforce the toy store concept

- **Contact page (`contact.html`)**
  - Simple contact form with client-side validation
  - Friendly response messaging on successful submission

- **JavaScript behavior (`script.js`)**
  - Centralized DOM handling for theme, cart, filter, and scroll controls
  - Local storage persistence for cart state
  - Clean cart rendering and user alerts for interactions

## Technology Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Why This Project Stands Out

This project is more than a static mockup: it is a complete mini storefront with stateful cart behavior, accessible styling, and a compelling narrative. The thoughtful UX details like theme toggling, a loader screen, and real-time product filtering make this project feel intentional and production-ready for a small brand showcase.

## Usage

1. Open `index.html` in a browser.
2. Browse the Shop page to filter products and add items to your cart.
3. Use the theme toggle to switch between light and dark mode.
4. Visit About to read the brand story, or Contact to test the form.

## Files

- `about.html` — Brand story and mission page
